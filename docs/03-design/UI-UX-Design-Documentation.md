# Cubiland — UI/UX Design Documentation

**Status:** Completed  
**Version:** 1.0  
**Last Updated:** 2026-11-21

## 1. Overview

This document provides an overview of the UI/UX design and visual interface of Cubiland.

The complete design, including wireframes, high-fidelity UI screens, design system, and interactive prototype, is maintained in Figma.

## 2. Figma Design File

**Figma Project:** [Cubiland — Figma Design](https://www.figma.com/design/koIB4YZF2P1bfkXj0xOpLa/Cubiland-%E2%80%94-UX-UI-Design?node-id=1-845&t=kjRGJoPFvCzcoXBv-1)

The Figma file contains:

- Design System — colors, typography, components, and design tokens.
- Sitemap — application structure and navigation hierarchy.
- User Flows — key user journeys and interactions.
- Wireframes — initial structural layouts of application screens.
- High-Fidelity UI — final visual designs of all application screens.
- Interactive Prototype — interactive navigation and interface behavior.
