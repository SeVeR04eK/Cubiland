# Cubiland — User Flows

**Version:** 1.0  
**Status:** Completed  
**Last Updated:** 2026-11-21

## 1. Overview

This document describes the main user journeys and interaction sequences within Cubiland.

User flows illustrate how users navigate the platform, access its features, and complete key tasks.

## 2. User Flow Index

| ID | User Flow | Description |
|---|---|---|
| UF-01 | Registration & Login | Account creation and authentication |
| UF-02 | Onboarding | Initial user setup |
| UF-03 | Course Learning | Accessing and completing lessons |
| UF-04 | Practice | Practicing algorithms and cubing techniques |
| UF-05 | Timer & Solve Recording | Timing and recording solves |
| UF-06 | Solve History | Reviewing previous solves |
| UF-07 | Statistics & Progress | Tracking performance and improvement |
| UF-08 | Gamification | Stars, achievements, levels, and rewards |

## 3. Detailed User Flows

### UF-01 — Registration & Login

**Goal:** Allow users to create an account or access an existing account.

Document the following:
- Registration entry point
- Account creation
- Input validation
- Authentication
- Successful login
- Error and recovery states

### UF-02 — Onboarding

**Goal:** Introduce new users to Cubiland and prepare their initial experience.

Document:
- Onboarding entry point
- Initial setup steps
- User preferences
- Completion state
- Navigation to the main dashboard

### UF-03 — Course Learning

**Goal:** Allow users to study structured speedcubing lessons.

Document:
- Opening the learning section
- Selecting a course
- Navigating lessons
- Viewing lesson content
- Completing lessons
- Tracking learning progress

### UF-04 — Practice

**Goal:** Allow users to practice algorithms and improve execution.

Document:
- Opening Practice
- Selecting an algorithm or practice category
- Viewing the algorithm
- Practicing execution
- Reviewing practice progress

### UF-05 — Timer & Solve Recording

**Goal:** Allow users to time solves and record their performance.

Document:
- Opening Timer
- Generating a scramble
- Starting the timer
- Stopping the timer
- Recording the solve
- Reviewing the result

### UF-06 — Solve History

**Goal:** Allow users to review and manage their solve records.

Document:
- Opening Solve History
- Viewing recorded solves
- Reviewing individual results
- Accessing available solve details

### UF-07 — Statistics & Progress

**Goal:** Help users understand their performance and improvement over time.

Document:
- Opening Statistics
- Viewing performance metrics
- Comparing results
- Reviewing progress over time

### UF-08 — Gamification

**Goal:** Encourage consistent learning and practice through gamification.

Document:
- Earning Stars
- Tracking levels
- Unlocking achievements
- Receiving rewards
- Viewing gamification progress
