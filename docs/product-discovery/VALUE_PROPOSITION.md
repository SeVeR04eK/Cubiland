# Value Proposition

**Document status:** Proposed product positioning  
**Version:** 1.0  
**Last updated:** 2026-11-11  
**Author:** Andrii Severyn

## 1. Product Value

Cubiland is designed to help people learn speedcubing and improve their solving performance through one connected learning and training environment.

The platform brings together:

- Structured courses and interactive lessons.
- Learning paths for different skill levels.
- Algorithm learning and practice.
- Guided exercises and training sessions.
- A speedcubing timer.
- Solve history and performance statistics.
- Progress tracking.
- Gamified progression, achievements, and rewards.
- Additional engagement features such as challenges, competitions, and community tools.

The long-term product direction also includes additional solving methods and support for other twisty puzzles.

## 2. Problem Addressed

People who learn or practice speedcubing may rely on separate tutorials, algorithm references, timers, statistics tools, and personal notes. These resources can make it difficult to connect learning activities with practical training and measurable progress.

Cubiland aims to reduce this fragmentation by bringing the main parts of the learning and training process together.

This problem definition is a product hypothesis and will be validated through user research.

## 3. Value Proposition Statement

> Cubiland helps people learn speedcubing and improve their solving skills by combining structured courses, algorithm practice, guided training, timing, and performance tracking in one platform.

## 4. Product Positioning

For people who want to learn or improve at speedcubing, Cubiland is an integrated learning and training platform that connects educational content with practical exercises and performance tracking.

Instead of relying on separate resources for tutorials, algorithm practice, timing, and statistics, users can follow a connected experience: learn a concept, practice it, record results, review progress, and continue toward the next goal.

## 5. Key User Benefits

| Benefit | Product capability |
|---|---|
| Structured learning | Courses organized into lessons and learning stages |
| Guided practice | Exercises and training sessions connected to learning content |
| Algorithm development | Algorithm references and focused practice |
| Measurable performance | Timer, solve history, and statistics |
| Learning continuity | User profile and saved progress |
| Skill development | Beginner and advanced methods, including CFOP |
| Motivation and engagement | Achievements, challenges, competitions, and community features |
| Personalization | Cosmetic customization through the planned reward shop |
| Long-term expansion | Additional courses, methods, and puzzle types |

## 6. Differentiation Direction

Cubiland's intended differentiation is based on the way product capabilities work together rather than on the existence of any single feature.

The main differentiation hypotheses are:

1. Learning content and practical training are connected in one workflow.
2. Users can review learning progress and solving performance in one place.
3. Training activities can be organized around a structured learning path.
4. The platform can support progression from beginner material to advanced solving methods.
5. Achievements and selected rewards can recognize meaningful milestones and encourage continued engagement.
6. The platform can expand to additional twisty puzzles without losing its connected learning experience.

These points describe the intended product direction. Their competitive significance must be validated through competitor evaluation and user research.

## 7. Reasons to Choose Cubiland

Users may choose Cubiland if they want to:

- Follow a guided learning path instead of searching for the next tutorial themselves.
- Practice algorithms and solving methods in the same environment where they learn them.
- Keep solve history and performance statistics connected to their learning progress.
- Track development through courses, training activities, and achievements.
- Use one account to follow progress across learning paths.
- Participate in additional challenges and community activities as those features become available.

## 8. Value Proposition Validation

The proposed value proposition will be evaluated through interviews and prototype testing.

Key questions:

- Does the problem described here match users' actual experience?
- Which part of the proposed platform is most valuable?
- Which existing tools would users continue using, and why?
- Would connecting lessons, practice, and statistics improve their workflow?
- Which capability would make users return regularly?
- Which features would users expect to be free?
- Would users pay for additional learning content or advanced functionality?

The value proposition will be refined using observed behavior and user feedback.

## 9. Short Value Proposition

**Learn. Practice. Track your progress.**

Cubiland brings speedcubing lessons, algorithm practice, timed solving, and progress tracking together in one platform.
