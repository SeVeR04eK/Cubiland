# **Cubiland**

An all-in-one speedcubing platform designed to help cubers learn, train, track performance, and continuously improve their solving skills.

[![Figma](https://img.shields.io/badge/Figma-Design-F24E1E?logo=figma&logoColor=white)](https://www.figma.com/design/koIB4YZF2P1bfkXj0xOpLa/Cubiland-%E2%80%94-UX-UI-Design?node-id=1-845&t=kjRGJoPFvCzcoXBv-1)

## **Project Status**

**Current Phase:** Architecture & Technical Design

Product discovery, requirements engineering, and UI/UX design have been completed. The project is currently focused on defining the system architecture, technical specifications, API contracts, data models, security, and infrastructure.

The initial development infrastructure has been established, including Docker Compose, PostgreSQL, Redis, RabbitMQ, and the Celery foundation for background task processing. Core application features are still under development.
