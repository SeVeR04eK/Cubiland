# Cubiland

An all-in-one speedcubing platform designed to help cubers learn, train, track performance, and continuously improve their solving skills.

## Project Status

**Current Phase**: UI/UX Design Completed

The product discovery, planning, and UI/UX design stages have been completed. The project includes a defined product concept, documented architecture, a complete high-fidelity interface, and an interactive prototype.
